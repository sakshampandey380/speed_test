# Internet Speed Test Console Script

A lightweight Python console script that measures sequential download speeds by making multiple requests to a target URL.

## Requirements
- Python 3.x (no external dependencies required; uses standard libraries `time`, `sys`, and `urllib`).

## How to Run

1. Clone the repository or download `speed_test.py`.
2. Open your terminal and run the script:
   ```bash
   python speed_test.py
